# Experiment log — every EXP, one row, sorted by date

**The index.** For the full story of any row, open its doc under `experiments/EXP-YYYY-NN-*.md`
(each has the pre-registered bar, method, and a "verify it yourself" appendix). This file exists
so "what's been tried" is a table scan, not a re-read of CLAUDE.md's history.

**When you close an experiment, add its row here in the same session** — this is the one file
that must never fall behind (EXP-2026-18 went undocumented in CLAUDE.md for weeks; that's the
failure mode this file exists to prevent).

Component tags refer to `docs/COMPONENT_FRAMEWORK.md`: **C1** detection, **C2** age (adult vs
child), **C3** gender.
